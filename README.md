# HarmonyQA: A Unified Framework for Harmonization Quality Assessment

## 📦 Installation

```bash
pip install -r requirements.txt
```

## 📥 Dataset

You can download the dataset from the following link:
[HarmonyQA](https://huggingface.co/datasets/sparkling621/HarmonyQAD))

## 🚀 Training

📈 Stage 1: Text-based quality training
```bash
sh shell/st1_train.sh
```

🎨 Stage 2: Fine-tune vision encoder and LLM with LoRA
```bash
sh shell/st2_train.sh
```
